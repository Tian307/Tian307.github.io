# 田洁 · Medical AI Builder

个人作品展示站，围绕临床流程、医学教学和医疗 AI 原型，展示问题背景、交互思路与可体验的前端演示。

## 展示内容

- **查房记录整理演示**：通过样例或输入文本，展示实体提取、结构化草稿与人工复核流程。浏览器可尝试语音识别；不支持时使用模拟转写。
- **评测报告平台演示**：展示字段识别、规则对齐、Bad Case 分析和报告生成的交互流程；页面中的结果是前端模拟。
- **实习到岗助手**：展示排班、到岗确认及异常提醒的交互原型，入口位于 `demos/intern-duty-assistant/`。
- **PDA 口述记录结构化助手**：展示护理任务文本解析、冲突提示和人工确认的概念流程。

## 本地查看

这是静态前端项目。克隆仓库后，可用本地 HTTP 服务打开根目录中的 `index.html`，例如：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。主要文件为 `index.html`、`styles.css`、`app.js`；图片和独立演示位于 `assets/` 与 `demos/`。

## 说明

站点用于展示交互和产品思路。部分处理使用样例数据或浏览器端规则模拟，不代表已经接入真实模型、医院系统或完整的报告导出服务。医疗相关输出仅用于演示，需由专业人员复核，不用于临床决策。
